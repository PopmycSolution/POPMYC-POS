PostgreSQL is not installed

POPMYC POS needs PostgreSQL to store your business data.
  1. Click Download PostgreSQL below to open the official installer.
  2. Download PostgreSQL 16 Windows x86-64 installer.
  3. Run the installer — use default settings and remember the password.
  4. Come back here and click Check Again.
🔌

PostgreSQL service is not running

PostgreSQL is installed but not currently started.
  1. Press Windows + R, type services.msc, press Enter.
  2. Find postgresql in the list.
  3. Right-click → Start.
  4. Click Check Again below.
🐘

Create POPMYC database

PostgreSQL is running. Enter the PostgreSQL administrator password to create the database automatically.
This is the password you set when installing PostgreSQL. It is used only once and never stored in logs.
